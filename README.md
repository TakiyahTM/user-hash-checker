# User Hash Checker (UHC)

User Hash Checker (UHC) is a small Python cybersecurity project I made to practise working with password hashes, JSON files, dictionaries and basic password checking.

The program takes SHA-256 password hashes from a JSON file and checks them against passwords from a `rockyou.txt` wordlist.

## What it does

UHC:

1. Asks for the path to a JSON file containing usernames and password hashes.
2. Loads the `rockyou.txt` password wordlist.
3. Creates a SHA-256 hash for each password in the wordlist.
4. Stores the hashes in a dictionary.
5. Checks each user hash against the dictionary.
6. Displays whether a matching password was found.
7. Saves the results to `results.json`.

The hashes from the wordlist are stored in a dictionary so the program can directly look up each user hash instead of checking every password one at a time.

## Example Input

The JSON file should contain users in this format:

```json
[
    {
        "user_name": "example_user",
        "user_password": "sha256_hash_here"
    }
]
```

The `user_password` value needs to be a SHA-256 hash.

An example JSON file is included in this repository as `example_users.json`.

## Example Output

The program displays results in the terminal like:

```text
example_user: Match Found
another_user: No Match
```

The results are also saved to `results.json`.

Example:

```json
[
    {
        "username": "example_user",
        "password": "password123",
        "password_found": true
    },
    {
        "username": "another_user",
        "password": "",
        "password_found": false
    }
]
```

## Requirements

* Python 3
* `rockyou.txt`
* A JSON file containing the user data

The program uses Python's built-in libraries:

* `hashlib`
* `json`

No additional Python packages are required.

## Running the Program

Make sure `User_Hash_Checker.py` and `rockyou.txt` are in the same folder.

Run the program with:

```bash
python3 User_Hash_Checker.py
```

The program will ask for the path to the JSON file:

```text
Enter your json file path or [E] to exit:
```

Enter `E` if you want to exit the program.

## How the Hash Checking Works

The program uses SHA-256 to hash every password in `rockyou.txt`.

The resulting hashes are stored in a Python dictionary, with the hash being used as the key and the original password being stored as the value.

When a user's hash is checked, the program looks for it directly in the dictionary.

If the hash exists, the original password from the wordlist is returned as a match.

If it doesn't exist, the program reports that no match was found.

## Limitations

This project is mainly for learning and demonstration purposes.

The program can only find passwords that are included in the `rockyou.txt` wordlist.

It also assumes that the password hashes provided in the JSON file are SHA-256 hashes.

If a password is not included in the wordlist, the program will return `No Match`.

## Disclaimer

This project should only be used with password data that you have permission to test.

The purpose of this project is to practise password hashing, wordlists, JSON handling, Python dictionaries and basic cybersecurity concepts.
